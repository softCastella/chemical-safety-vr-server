## 관찰된 문제

초기 회귀 화면에서는 소녀가 아래로 밀리고, CTA가 가운데보다 오른쪽에 놓였으며 너무 아래에 있어 바닥 그림자가 잘리거나 보이지 않았다. CTA의 궤적과 그림자도 같은 중심을 공유하지 않았다. 환경에 따라 별 마스크가 표시되지 않아 사각 CTA만 보이기도 했다.

후속 수정 과정에서는 소녀 위치와 CTA 중심을 복구했지만 다음 회귀가 추가로 발생했다.

- 별의 바깥 반경과 안쪽 골을 함께 줄여 별이 작아졌다.
- 작아진 별 외곽선이 CTA 텍스트에 붙어 보인다.
- 안쪽으로 파인 꼭짓점까지 둥글어져 별 모양이 부자연스럽다.
- 어두운 배경에서 바닥 그림자를 식별하기 어렵다.
- 사각형으로 번지는 필터를 제거하면서 별 마스크 레이어의 hover 강화 글로우를 함께 복구하지 않아 hover 효과가 사라졌다.

## 근본 원인

### 기존 코드 회귀

`7bb56d8`에서 기존 CSS 뒤에 약 200줄의 중복·충돌 규칙이 추가됐다.

- 데스크톱 `.splash`를 고정 높이에서 `height:auto`, `overflow:visible`과 큰 하단 padding 구조로 바꾸면서 `position:absolute; bottom:0`인 소녀의 기준 박스가 길어졌다. 이 때문에 소녀가 아래로 밀렸다.
- `.play-scroll-button` 전체에 `transform:rotateY(...)` 애니메이션을 적용해 원래 수평 중앙 정렬에 사용하던 `translateX(-50%)`를 덮어썼다. 이 때문에 CTA가 오른쪽으로 이동했다.
- CTA와 `.hero-actions::after` 바닥 그림자가 서로 다른 위치 규칙을 사용해 중심과 높이가 분리됐다.
- 외부 SVG 마스크 의존성과 버튼 전체 `filter`가 섞여 `file://` 또는 자산 응답 실패 시 별이 사라지고 사각형 글로우가 나타날 수 있었다.

`9a7da20`은 `clip-path`를 추가했지만 실패하는 외부 마스크 선언도 그대로 유지했다. 마스크가 투명 결과를 만들면 `clip-path`만으로 별 표시를 복구할 수 없어 완전한 fallback이 아니었다.

사용자가 처음 언급한 `8f082b3`은 현재 clone의 `git log --all`에서 찾지 못했다. 이 SHA의 변경 내용은 확인된 사실로 사용하지 않는다.

### 후속 수정 과정의 오류

충돌하던 후반 CSS를 제거하고 버튼 전체 필터를 끄는 과정에서 CTA 필수 효과를 항목별로 보존하는 회귀 확인을 하지 않았다. 사각형 글로우를 없앤 뒤 글로우를 별 마스크 pseudo-element로 완전히 옮기지 않았고, 별을 덜 뾰족하게 만들 때 바깥 끝의 곡률만 조절하지 않고 전체 외곽 반경과 안쪽 골까지 축소했다. 정지 화면의 위치를 먼저 확인하고 기본·hover 상태와 전체 애니메이션을 같은 검증 묶음으로 확인하지 않은 것이 추가 회귀의 원인이다.
