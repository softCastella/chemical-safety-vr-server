# TYCHE WORKS 사이트 작업 기록

- 작업일: 2026-08-24
- 대상: TYCHE WORKS 정적 HTML 사이트
- 작업 경로: `tycheworks-site-final-routed`

## 1. 사이트 구조와 내비게이션

- 홈 내비게이션에서 중복된 `ABOUT` 메뉴를 제거하고 `BRAND`로 통합했다.
- 홈 내비게이션 순서를 `WORKS / BRAND / VR / GAME / APP / CONTACT`로 정리했다.
- BRAND, IMMERSA, SPARK, LOOP, IMMERSA 제품 상세 페이지에 CONTACT 링크를 추가했다.
- 서브페이지의 CONTACT는 홈의 `#contact` 섹션으로 연결했다.
- 라인 페이지에서 기존 `HOME` 표기를 `TYCHE WORKS`로 변경했다.
- 각 라인 로고의 링크 목적지를 다음처럼 통일했다.
  - IMMERSA 로고 → `/immersa/index.html`
  - SPARK 로고 → `/spark/index.html`
  - LOOP 로고 → `/loop/index.html`
- IMMERSA 제품 상세 페이지의 로고도 IMMERSA 라인 홈으로 연결했다.
- 브랜드 소개 페이지에 있는 각 라인 로고도 해당 라인 페이지로 연결했다.

## 2. 헤더 로고 정렬

- SPARK와 LOOP의 기존 크기를 기준으로 사용했다.
- 홈 TYCHE 로고는 기존보다 확대해 라인 로고와 체감 크기를 맞췄다.
- IMMERSA 로고는 SPARK·LOOP와 같은 너비 및 최대 높이 기준으로 조정했다.
- 데스크톱 라인 로고 기준: `205px`, 최대 높이 `70px`.
- 모바일 라인 로고 기준: `155px`, 최대 높이 `54px`.
- SPARK·LOOP 로고는 세로 위치를 2px 위로 보정했다.
- IMMERSA·SPARK·LOOP 로고는 최종적으로 원래 기준에서 4px 왼쪽으로 이동했다.
- 로고 PNG의 투명 여백이 서로 달라 캔버스 크기가 아닌 실제 보이는 크기를 기준으로 조정했다.

## 3. 홈 Featured Releases 캐러셀

- 섹션 제목을 `Now on Tyche`로 변경했다.
- 오른쪽에 있던 순환 노출 설명 문구를 제거했다.
- 배너 외곽선을 제거했다.
- 부모 배경을 투명하게 만들고 트랙·슬라이드에 동일한 라운드와 클리핑을 적용해 모서리의 검정색 번짐을 제거했다.
- 배너 라운드를 `22px`로 조정했다.
- 데스크톱 기본 높이를 약 `300px`로 축소했다.
- 태블릿은 약 `320px`, 모바일은 약 `330px`로 유지했다.
- 작품 제목 최대 크기를 `40px`로 줄였다.
- 배너 내부 상태, 카테고리, 설명, 링크, 페이지 번호의 최소 글자 크기를 `16px`로 맞췄다.
- 상태 뱃지와 카테고리 문구 사이에 `12px` 간격을 추가했다.

## 4. Meta Horizon 채널 카드

- IMMERSA 제품 상세 화면에서 전체 폭 배너 대신 작은 독립 채널 카드로 변경했다.
- 흰색 카드에 Meta Horizon 로고 하나만 표시했다.
- 카드 크기는 약 `208 × 78px`이며 라운드는 `14px`다.
- 아웃라인은 Serenity와 Meta Blue의 중간색인 `#6F9FE8`로 적용했다.
- `Meta Horizon에서 만나보세요 / Coming soon →` 문구는 카드 바로 아래 한 줄로 배치했다.
- 중복되던 Meta Horizon 상태 패널은 화면에서 숨겼다.
- 실제 채널 주소가 확정되기 전까지 링크는 준비 상태다.

## 5. CONTACT 섹션과 이메일 보호

- 홈 마지막 부분에 이름, 회신 이메일, 문의 내용을 입력하는 CONTACT 폼을 추가했다.
- 모든 공개 HTML에서 회사 이메일 주소와 `mailto:` 링크를 제거했다.
- 이전 마크업이 캐시에 남더라도 이메일이 표시되지 않도록 `.contact-email`을 강제로 숨겼다.
- 폼은 공개 이메일 주소 대신 `/api/contact`로 POST하도록 구성했다.
- 실제 메일 전달을 위해서는 배포 서버에서 `/api/contact` 보안 중계 기능을 추가해야 한다.
- 수신 이메일 주소는 공개 HTML이 아닌 서버 환경 변수 또는 비공개 설정에만 보관해야 한다.
- 권장 서버 보호 기능:
  - CAPTCHA 또는 Turnstile
  - 요청 횟수 제한
  - 입력값 검증 및 길이 제한
  - 스팸·봇 차단

## 6. 공통 풋터

- 홈, BRAND, IMMERSA, IMMERSA 제품 상세, SPARK, LOOP에 공통 풋터를 적용했다.
- 풋터 구성은 시각적으로 `로고 / COMPANY / LINES / CHANNEL` 순서다.
- 로고 아래 부가 설명은 넣지 않았다.
- COMPANY에는 BRAND, WORKS, CONTACT를 배치했다.
- LINES에는 IMMERSA, SPARK, LOOP를 배치했다.
- CHANNEL에는 Meta Horizon과 Coming soon 상태를 배치했다.
- 이메일 주소는 풋터에 노출하지 않았다.
- 배경은 아주 옅은 쿨그레이 `#F8F9FB`다.
- 배경에 `34px` 간격의 미세한 연회색 그리드 패턴을 적용했다.
- 라인별 페이지는 상단에 각 라인 색상 포인트를 유지했다.
  - IMMERSA: Blue
  - SPARK: Orange
  - LOOP: Yellow
- 저작권 위 구분선을 `#C8CED6`으로 한 단계 진하게 조정했다.
- 저작권 문구는 데스크톱과 모바일 모두 가운데 정렬했다.
- COMPANY에 CONTACT가 있으므로 풋터 최하단의 중복 CONTACT는 숨겼다.

## 7. 불필요한 하단 CTA 제거

- IMMERSA 페이지의 `TYCHE WORKS로 돌아가기` 대형 CTA를 제거했다.
- BRAND 페이지의 `Different lines. One experience philosophy.` 대형 CTA와 홈 이동 버튼을 제거했다.
- 본문이 공통 풋터로 자연스럽게 이어지도록 정리했다.

## 8. SPARK·LOOP 준비중 화면

- 준비중 텍스트 묶음을 화면의 가로·세로 중앙에 배치했다.
- 풋터가 추가된 뒤에도 중앙 콘텐츠가 겹치지 않도록 본문 레이아웃을 그리드 중앙 정렬 방식으로 변경했다.
- SPARK와 LOOP의 라인 컬러 포인트를 유지했다.

## 10. 후속 작업

1. 배포 환경이 결정되면 `/api/contact` 메일 중계 기능을 구현한다.
2. 수신 주소와 메일 서비스 인증값은 서버 비공개 환경 변수로 설정한다.
3. Meta Horizon 실제 채널 주소가 확정되면 임시 링크를 교체한다.
4. 실제 배포 루트가 바깥 폴더인지 안쪽 복제 폴더인지 확인한 뒤 중복 디렉터리 정리를 검토한다.
5. 데스크톱·태블릿·모바일에서 최종 시각 검수를 진행한다.
