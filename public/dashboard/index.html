모드별 시작과 완료

시작·완료 이벤트를 각각 집계한 기록입니다.

두 이벤트의 단순 차이는 이탈자 수나 완료율이 아닙니다. 진행 중인 실행과 기간 경계가 포함될 수 있습니다.

사용자 ID 수는 Meta 앱 ID 또는 설치 식별자로 연결된 내부 참가자 ID 기준이며 실제 사람 수와 다를 수 있습니다. 신규 사용자는 저장된 첫 세션의 시작일, 기존 사용자는 첫 플레이일 이후 다른 날짜의 플레이를 기준으로 합니다. 같은 날 재실행은 기존 사용자에 포함하지 않으며, 날짜 경계는 UTC입니다. 종료 이유와 재방문 이탈은 이 화면에서 추정하지 않습니다.
