01 · APP ENTRY

공통 씬 진입 시간

시나리오·모드 선택 전에 지나가는 경로라 모든 표본 세션을 함께 계산합니다.

시나리오·모드와 별도
현재 빌드 경로ProjectSettings/EditorBuildSettings.asset

씬이전 씬 도착 → 이번 씬 평균앱 시작 → 이번 씬 평균시간이 기록된 플레이

씬 사이 평균은 순수 로딩시간이 아닙니다. 이전 씬에 머문 시간과 대기를 포함합니다. 화면·입력이 정상 준비됐는지는 별도 계측이 없습니다.

02 · FLOW

단계 사이 평균 시간

선택한 시나리오·모드에서 모드 시작과 다음 단계 도착 사이의 기록을 묶습니다.

조건별 모드 회차
단계 이동평균 경과시간평균에 포함된 실행

단계 간격에는 안내, 입력 대기와 이동이 포함될 수 있습니다. 단계 자체의 순수 작업시간이나 정상·지연 판정으로 읽지 않습니다.

03 · PPE

PPE별 평균 시간

같은 조건의 모드 실행에서 관측된 PPE 잡기와 사용 판정을 구분합니다.

조건별 모드 회차

다음 PPE를 잡기까지 서로 다른 장비가 실제로 잡힌 시각 사이의 평균입니다.

잡은 PPE → 다음 PPE평균 경과시간평균 잡기 실패평균에 포함된 실행

같은 PPE를 연속해서 다시 잡은 기록은 하나의 구간에 포함합니다. ‘잡기 실패’는 그립 입력 후 PPE 선택으로 이어지지 않은 결과이며 사용자 실수나 장비 결함의 원인 판정은 아닙니다. 한 회차에 같은 장비 순서가 여러 번 나오면 그 회차의 평균을 먼저 구합니다.

PPE 첫 시도부터 사용 판정까지 잡기 또는 검사 시작 기록이 판정 전에 있는 경우만 계산합니다.

PPE평균 경과시간평균에 포함된 실행

관측되지 않은 구간은 평균에 넣지 않습니다. 표본이 적은 평균은 일반적인 기준시간으로 확정하지 않습니다.
