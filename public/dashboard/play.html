01 · REVIEW FIRST

먼저 볼 구간

기준 실행보다 시간이 길게 기록된 구간과 미완료·잡기 실패·오답 기록을 보여 줍니다.

선택 조건

시간 차이는 같은 시나리오·모드·구간의 기준 실행 1회와 현재 기록의 중앙값을 대조합니다. 앱 버전과 실행 환경이 달라 차이만으로 원인을 확정하지 않습니다. 완료 미확인·잡기 실패·오답은 별도 관측 신호이며, 참여자 ID가 없거나 표본이 적으면 다수 사용자에게 공통된 문제로 판정하지 않습니다.

누적시간은 앱 시작부터 해당 씬 도착까지입니다. 씬 사이 시간은 이전 씬 도착부터 해당 씬 도착까지이며, 이전 씬에 머문 시간과 대기를 포함하므로 순수 로딩시간이 아닙니다. 화면·입력이 정상 준비됐는지는 별도 계측이 없습니다.

03 · FLOW

단계별 진행 시간

교육·훈련·테스트 중 하나의 모드가 시작된 뒤, 첫 상태가 기록된 시점부터 다음 상태 또는 모드 완료까지 봅니다.

조건별 모드 실행
단계 구간기준시간실제 중앙값차이기록된 실행시간을 잰 기록

모드 시작부터 첫 상태 기록까지의 시간은 계산하지 않습니다. 표에 표시된 단계 시간에는 안내·입력 대기·행동·상태 전환이 함께 들어가며, 긴 시간만으로 헤맨 원인을 확정하지 않습니다.

04 · PPE

다음 보호구를 잡기까지 걸린 시간

한 보호구를 잡은 시각부터 다음 보호구를 잡은 시각까지 계산합니다.

조건별 모드 실행

먼저 잡은 보호구

다음에 잡은 보호구

다음에 잡은 보호구기준시간실제 중앙값차이잡기 실패가 있었던 실행기록된 실행시간을 잰 기록

‘잡기 실패가 있었던 실행’은 해당 보호구 사이에서 실패 기록이 한 번 이상 남은 실행 수이며 기준값이 아닙니다. 기준 실행 한 회차의 보호구 순서는 필수 순서가 아닙니다. 현재 기록에만 있는 앞·뒤 보호구 조합은 ‘기준 없음’으로 표시합니다. 오른쪽에는 실제 또는 기준 실행에서 관측된 다음 보호구만 나타납니다. 두 보호구 사이에는 이동·안내·검사·대기가 포함될 수 있습니다. 같은 순서가 한 실행에서 반복되면 그 실행의 평균을 먼저 구합니다.

PPE 검사·판단 구간 더 보기

해당 PPE의 첫 잡기 입력 또는 검사 시작부터 선택 결과까지의 경과시간입니다. 승인된 사용만의 시간이 아니며 원인 판정에 사용하지 않습니다.

조건별 모드 실행
문항 순번오답 / 응답오답 비율응답한 실행

문항 순번별 실제 응답 이벤트만 집계합니다. 순번이 같아도 문항 내용이 동일한지는 현재 데이터로 검증되지 않습니다. 점수·합격·불합격을 이 표에서 만들지 않습니다.
